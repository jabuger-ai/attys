# AttysHRV

![alt tag](attyshrv.jpg)

## Prerequisites

1. Edit `app/src/main/cpp/CMakeLists.txt` and point it to the openXR API:
  `set(OCULUS_OPENXR_MOBILE_SDK /home/yourname/ovr_openxr_mobile_sdk)`

2. Clone AttysComm and modify `app/build.gradle` so that it points
   to AttysComm.

## Compile & run

Start Android Studio, open AttysHRV and click `run`.
